    新しい学生の GPA を予測する式を, 学習用の 70 人で比べます. 候補は GPA の重回帰分析の式 A, 運動時間を足した式 B, アルバイト時間を外した式 C です.

    合成 GPA データの準備を実行してから, 学習用データを 14 人ずつの 5 組に分けます. 1 組を検証用とし, 他の 4 組の 56 人で係数を求めます. 検証用の組を入れ替えて 5 回予測し, 5 組の MSE の平均を交差検証の MSE (CV MSE) とします. 組の分け方はすべての候補で共通です. 各データの役割は訓練データ・検証データ・テストデータで確認できます.

    formulas = {
    "A": "GPA ~ Scholarship + Study_Hours + Part_time_Work",
    "B": "GPA ~ Scholarship + Study_Hours + Part_time_Work + Sports_hours",
    "C": "GPA ~ Scholarship + Study_Hours",
}
folds = KFold(n_splits=5, shuffle=True, random_state=0)
splits = list(folds.split(train))

scores = []
for name, formula in formulas.items():
    validation_errors = []
    for fit_indices, validation_indices in splits:
        fitting = train.iloc[fit_indices]
        validation = train.iloc[validation_indices]
        fit = smf.ols(formula, data=fitting).fit()
        predicted = fit.predict(validation)
        validation_errors.append(mean_squared_error(validation["GPA"], predicted))

    full_fit = smf.ols(formula, data=train).fit()
    scores.append(
        {
            "Model": name,
            "CV MSE": sum(validation_errors) / len(validation_errors),
            "AIC": full_fit.aic,
        },
    )

scores = pd.DataFrame(scores)
print(scores.to_string(index=False, float_format=lambda value: f"{value:.5f}"))
    Model  CV MSE      AIC
    A 0.06265 -9.05519
    B 0.06339 -7.09237
    C 0.08188 18.55755

    KFold が返すのは行の位置なので, iloc で学習用データから行を取り出します. AIC は候補ごとに同じ 70 人で当てはめて計算します. statsmodels の aic は誤差分散をパラメータ数に含めないため, 誤差分散を含めて p=k+2 とする情報量規準の式より, 同じ式の AIC が 2 小さくなります. 候補間の AIC の差はどちらの数え方でも同じなので, AIC が最小になる式も同じです.

    CV MSE と AIC はともに小さい値を選ぶ規準で, このデータではどちらも式 A が最小です. GPA の二乗誤差を測るのが目的なので, CV MSE を採用基準にします. 式を決めたら, 学習用の 70 人で係数を求め直し, テストデータの 30 人で MSE を 1 回だけ求めます.

    best_name = scores.loc[scores["CV MSE"].idxmin(), "Model"]
best_fit = smf.ols(formulas[best_name], data=train).fit()
test_prediction = best_fit.predict(test)
test_mse = mean_squared_error(test["GPA"], test_prediction)
print(f"Selected model: {best_name}")
print(f"Test MSE: {test_mse:.5f}")
    Selected model: A
Test MSE: 0.03363

    式 A のテスト MSE は約 0.034 で, CV MSE の約 0.063 を下回りました (単位はいずれも GPA 点の二乗). 評価に使う学生が違い (テストは 30 人の 1 組), 係数を求めた人数も交差検証では 56 人, 最終評価では 70 人なので, 今回の大小関係だけから一般の傾向は判断できません. 式 A と B の CV MSE の差は約 0.00074 で, 式を選ぶときは表示のために丸める前の値を使います. 候補をさらに増やしたときに, 選択に使った誤差をどう読むかは 説明変数の組み合わせを交差検証で比べるで扱います.
