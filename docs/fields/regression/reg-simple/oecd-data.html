    fertility_rates.csv と time_used.csv をダウンロードし, コードと同じフォルダに置いてください. コードはそのフォルダから実行してください.

    import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import statsmodels.api as sm
from adjustText import adjust_text

fertility = pd.read_csv("fertility_rates.csv")
time_use = pd.read_csv("time_used.csv")

    Country は国名, Fertility は合計特殊出生率です. 時間配分の表では, Paid が有償労働, Unpaid が無償の家事, Care が育児などのケアに対応します. 男性がこの 3 項目に使う時間のうち, 家事・育児に使う割合を百分率で計算し, r に格納します.

    unpaid_and_care = time_use["Unpaid"] + time_use["Care"]
total_work = time_use["Paid"] + unpaid_and_care
time_use["r"] = 100 * unpaid_and_care / total_work

    出生率の表ではトルコが Türkiye, 時間配分の表では Turkey と表記されています. 出生率の表の表記を Turkey にそろえてから, Country をキーに結合します. validate="one_to_one" を指定すると, 同じキーが片方の表に複数回現れたときにエラーになります. 外部結合 (how="outer") では, 片方の表にしかない行も残ります. indicator=True で追加した _merge 列で, それぞれの行がどちらの表にあったかを確かめます.

    fertility["Country"] = fertility["Country"].replace({"Türkiye": "Turkey"})
joined = fertility.merge(
    time_use[["Country", "r"]],
    on="Country",
    how="outer",
    validate="one_to_one",
    indicator=True,
)

unmatched = joined.loc[joined["_merge"] != "both", ["Country", "_merge"]]
print(unmatched.to_string(index=False))

    left_only の行には出生率だけがあります. 今回の表には, 時間配分の表にだけある right_only の行はありません. both の行を残し, dropna() で数値が欠けている行を除きます. 両方の値がそろったのは 22 か国です. 本文では, 旧教材と同じくメキシコを外した 21 か国を使います. メキシコを加えた場合は Exercise REG-SIMPLE-1 で確かめます.

    matched = joined.loc[joined["_merge"] == "both", ["Country", "Fertility", "r"]]
countries = matched.set_index("Country").dropna()
analysis = countries.drop(index="Mexico")

print(f"Matched: {len(countries)}, used in the main example: {len(analysis)}")
