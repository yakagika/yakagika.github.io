    係数と信頼区間

    取得確率を 0 から 1 の範囲で表すため, 勉強時間とアルバイト時間を説明変数にしたロジスティック回帰を当てはめます. sm.Logit に目的変数と説明変数を渡し, fit() で係数を最尤法によって推定します. sm.add_constant は, 切片 \beta_0 を推定するための 1 の列を先頭に加えます. disp=False を指定すると, fit() は最適化の経過を表示せずに結果を返します.

    hours = credit[["Study_Hours", "Part_time_Work"]]
predictors = sm.add_constant(hours)
response = credit["Credit"]
result = sm.Logit(response, predictors).fit(disp=False)

intervals = result.conf_int()
intervals.columns = ["lower_95", "upper_95"]
coefficient_table = intervals.assign(coefficient=result.params)
coefficient_table = coefficient_table[["coefficient", "lower_95", "upper_95"]]
print(coefficient_table.to_string(float_format="{:.3f}".format))
                    coefficient  lower_95  upper_95
const                -2.166    -3.378    -0.954
Study_Hours           0.603     0.431     0.775
Part_time_Work       -0.197    -0.281    -0.112

    coefficient は対数オッズの尺度での推定値です. lower_95 と upper_95 は, モデルの仮定のもとで標本の取り方によるばらつきを反映した 近似的な 95% 信頼区間の両端です.

    勉強時間の係数 \hat\beta_1 は 0.603 です. アルバイト時間が等しい学生どうしで, 勉強時間が週 1 時間長い学生の取得の対数オッズは 0.603 高いと推定されます. 同じ勉強時間の学生どうしでは, アルバイト時間が週 1 時間長い学生の取得の対数オッズは 0.197 低いと推定されます.

    推定手順と各係数の検定は, 次の出力で確かめられます.

    print(result.summary())
print("反復回数", result.mle_retvals["iterations"])

    出力の上段から推定方法, 尤度, 収束を示す行を抜き出し, 続けて係数表の見出しと勉強時間の行, 最後に反復回数を示します.

    Method:                           MLE   Df Model:                            2
Date:                Mon, 23 Nov 2026   Pseudo R-squ.:                  0.4102
Time:                        16:11:58   Log-Likelihood:                -81.739
converged:                       True   LL-Null:                       -138.59
                     coef    std err          z      P>|z|      [0.025      0.975]
Study_Hours        0.6028      0.088      6.875      0.000       0.431       0.775
反復回数 7

    出力の Method は MLE (最尤法), converged は True, 反復回数は 7 です. 係数を更新する数値計算が収束したかはここで確かめます. 係数表の z は推定値を標準誤差で割った値で, 勉強時間では 6.875 です. P>|z| は母集団の係数が 0 という帰無仮説のもとでの両側 P 値です. 表の 0.000 は小数第 3 位までの丸め表示です.

    Log-Likelihood は両方の時間を使った式の最大対数尤度 (−81.739), LL-Null は切片だけの式の最大対数尤度 (−138.59) です. Pseudo R-squ. の 0.4102 は, この二つの値から 1-(-81.739)/(-138.59) と計算した疑似決定係数です. 切片だけの式からの当てはまりの改善を, 対数尤度で表しています.

    同じ 0/1 の応答を, 学生ごとに試行回数 1 の二項分布で表すこともできます. Binomial() の既定のリンク関数はロジットなので, 同じ説明変数を渡せば推定する式も共通です.

    binomial_fit = sm.GLM(response, predictors, family=sm.families.Binomial()).fit()
print(np.allclose(result.params, binomial_fit.params))
    True

    両方の方法で求めた三つの係数は, 数値計算の許容誤差の範囲で一致します.

    オッズ比と信頼区間

    推定した係数は, 一方の時間が同じで, もう一方の時間が週 1 時間違う学生どうしの対数オッズの差を表します. 取得オッズを何倍かで読むには, 対数オッズの差を指数関数に通します. 係数を指数関数に通した値が, 比べる時間が週 1 時間違う学生どうしのオッズ比です. 指数関数は単調に増加するので, 信頼区間の下限と上限にも同じ変換を施します. オッズ比を示す表には, 勉強時間とアルバイト時間の係数を使います.

    odds_ratio_table = np.exp(coefficient_table.loc[hours.columns])
odds_ratio_table = odds_ratio_table.rename(columns={"coefficient": "odds_ratio"})
print(odds_ratio_table.to_string(float_format="{:.3f}".format))
                    odds_ratio  lower_95  upper_95
Study_Hours          1.827     1.539     2.170
Part_time_Work       0.821     0.755     0.894

    アルバイト時間が同じ学生どうしで, 勉強時間が週 1 時間長い学生の取得オッズは短い学生の約 1.83 倍です (95% 信頼区間は約 1.54 から 2.17). 勉強時間が同じ学生どうしでは, アルバイト時間が週 1 時間長い学生の取得オッズは短い学生の約 0.82 倍です (95% 信頼区間は約 0.76 から 0.89).
