    前提となるブロック

    • 目的ごとに変数を選ぶ

    予測: 交差検証で選び, テストデータで 1 回だけ評価するでは, GPA の予測に使う 3 つの候補の式を交差検証で比べました. ここでは, 候補を 4 つの説明変数のうち 1 つ以上を使うすべての組み合わせ (15 通り) に広げます. GPA の予測式を選ぶために測った誤差と, 選んだ後に測った誤差を並べます. 独立な乱数を使う別の実験では, 無関係な変数から P 値で選んだときに何が残るかを調べます.

    合成 GPA データの準備

    multiple_regression.csv には, 合成した 100 人分のデータが入っています. CSV をダウンロードしてコードと同じフォルダに置き, そのフォルダからコードを実行してください. index_col=0 で先頭列の行番号を行のインデックスとして読み込みます.

    from itertools import combinations

import pandas as pd
import statsmodels.formula.api as smf
from sklearn.metrics import mean_squared_error
from sklearn.model_selection import KFold, train_test_split

df = pd.read_csv("multiple_regression.csv", index_col=0)
train, test = train_test_split(df, test_size=0.3, random_state=0)
print(f"Training: {len(train)}, held out: {len(test)}")
    Training: 70, held out: 30

    読み込んだ直後に最終評価用の 30 人を取り分けます. 変数の組み合わせを比べるために使うのは, 残った学習用の 70 人です.
