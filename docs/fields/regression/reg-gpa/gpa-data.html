    回帰式を当てはめた学生と, 新しい学生への予測を評価する学生を, データを読む段階で分けます. 学習用の学生について GPA と時間の関係を図で確かめ, 奨学生区分を 0 と 1 で式に入れます. 勉強時間が週 1 時間違う場合の平均 GPA の差を係数から求め, 式が学習用の GPA をどの範囲でよく表すかを図で確かめます.

    この CSV には, 偏回帰係数とそろえる条件で述べた仕組みで作った架空の学生 100 人分のデータが入っています. 奨学生区分は質的変数で, GPA と 3 種類の時間は量的変数です.

    列 内容
    GPA GPA (0〜4 点)
    Scholarship 奨学生かどうか (True または False)
    Study_Hours 週あたりの勉強時間 (時間)
    Part_time_Work 週あたりのアルバイト時間 (時間)
    Sports_hours 週あたりの運動時間 (時間)

    CSV をダウンロードしてコードと同じフォルダに置き, そのフォルダからコードを実行してください. 先頭列は CSV の保存時に書き出された行番号です. index_col=0 で行のインデックスとして読み込みます.

    import matplotlib.pyplot as plt
import pandas as pd
import seaborn as sns
import statsmodels.formula.api as smf
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import MinMaxScaler, StandardScaler
from statsmodels.graphics.regressionplots import plot_partregress_grid
from statsmodels.stats.outliers_influence import variance_inflation_factor

df = pd.read_csv("multiple_regression.csv", index_col=0)
train, test = train_test_split(df, test_size=0.3, random_state=0)
print(f"Training: {len(train)}, held out: {len(test)}")
    Training: 70, held out: 30

    読み込んだ直後に最終評価用の 30 人を取り分けます. random_state=0 は分割を再現するための指定です. 残った 70 人 (train) で図と表を作り, 回帰式を求めます.

    学習用データの先頭 4 行を表示します. 1 行が学生 1 人に対応し, 左端の数字は元の行番号です.

    print(train.head(4).to_string(float_format=lambda value: f"{value:.2f}"))
