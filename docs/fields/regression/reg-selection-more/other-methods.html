    有意性による除外

    各変数を一つずつ回帰して有意になったものだけを重回帰の候補にする方法と, 重回帰の中で有意でないものを外す方法があります. 単回帰と重回帰では, 比較でそろえる条件が違うため, 一方で P 値が大きい変数がもう一方でも同じ結果になるとは限りません. 関係の定量化では, 問いで定めた比較に必要な条件は式に残します. 予測では, 係数の検定を通るかと, その変数で未使用データの誤差が減るかは異なる問いです. 探索で有意性を手がかりにした場合は, 候補をどの手順で選んだかも記録します.

    正則化

    説明変数が多いと, 最小二乗法で求める係数は標本が変わるたびに大きく動くことがあります. 正則化では, 残差平方和に係数の大きさに応じた罰則を加え, その合計が最小になるように係数を求めます. 線形回帰では e_i=y_i-(\beta_0+\sum_{j=1}^k\beta_j x_{ij}) を候補の係数に対する残差とします. 係数を同じ尺度で扱うために, 説明変数は通常, 訓練データを使って標準化します. 以下の式では切片を罰則から外します.

    リッジ回帰では, 係数の二乗に応じた罰則を加えます.

    \sum_{i=1}^n e_i^2+\lambda\sum_{j=1}^k\beta_j^2.

    ラッソでは, 係数の絶対値に応じた罰則を加えます.

    \sum_{i=1}^n e_i^2+\lambda\sum_{j=1}^k|\beta_j|.

    \lambda\geq 0 は罰則の強さです. リッジ回帰は係数を 0 に近づけます. ラッソでは係数がちょうど 0 になることがあり, 対応する変数を使わない式が得られます. 予測に使う \lambda は, 例えば交差検証で誤差を比べて選びます. 罰則を加えて求めた係数は最小二乗法の係数と異なるため, 最小二乗法の検定や区間の計算をそのまま使うことはできません. ラッソで選んだ変数の係数を推論する方法は選んだ後の推論で扱います.

    交差検証

    テストデータを取り分けた残りをいくつかの組に分け, 各組を順に検証用とします. 候補の式ごとに, 検証用以外の組で係数を求め, 検証用の組で予測誤差を測ります. 例えば 平均二乗誤差で比べるなら, どの候補にも同じ分け方と誤差の指標を使います. 標準化に使う平均や標準偏差も, 各回で当てはめに使う組だけから求めます. 変数の候補をデータで絞る手順ごと比べる場合は, 候補の絞り込みも各回で当てはめに使う組で行います. 検証誤差によって選んだ式の最終評価には, 選択と当てはめに使わなかったテストデータを使います. テストデータで誤差を測る計算は未使用のデータで予測の誤差を測る, GPA で交差検証により式を選ぶ計算は予測: 交差検証で選び, テストデータで 1 回だけ評価するにあります.

    目的と手法の対応

    手法 予測での使い方 探索での使い方 関係の定量化・因果推論での限界
    有意性による除外 候補の絞り込みに使う場合も, 採否は未使用データの予測誤差で判断します. 次に調べる変数を絞れます. P 値で比較の条件や調整の要否は決められません. 選んだ式を同じデータで検定すると, 選択の影響を受けます.
    AIC・BIC AIC は対数尤度で測る予測の候補比較に使えます. BIC は候補モデルの比較に使う規準で, 予測誤差は別に測ります. 規準の値が近い式を残し, 仮説の候補にできます. 規準の値には, 問いが指定する比較条件や因果の構造は反映されません.
    リッジ回帰・ラッソ 係数に罰則を加え, 検証データや交差検証で罰則の強さを選びます. ラッソで残った変数を, 次に調べる候補にできます. 罰則を加えた係数には, 通常の最小二乗法の推測を適用できません. 残る変数は, 因果の構造から決まる調整変数とは限りません.
    交差検証 当てはめに使わなかった組の誤差で式や罰則の強さを比べます. 予測に結びつきそうな式の候補を絞れます. 交差検証の誤差で, 係数の区間の妥当性や因果の仮定は判定できません.
