    前提となるブロック

    • 回帰分析とは何か

    目的変数には, GPA のような量的な値のほかに, 単位を取得したかどうかのような 0 か 1 の値, 1 学期の欠席回数のような 0 以上の整数 (個数), 通学時間のような正の連続値があります. 母回帰式と誤差で扱った線形回帰では, 説明変数の値が同じ観測の目的変数は, 回帰式の一次式の値を平均とする正規分布に従い, その分散は説明変数の値によらず等しいと仮定しました. この仮定のまま欠席回数や単位の取得を表すと, 一次式の値が負になったり 1 を超えたりして, 個数や確率として読めない平均が出ます. 欠席回数のように平均が大きいほどばらつきも大きい目的変数では, 分散が等しいという仮定も成り立ちません.

    一般化線形モデル (generalized linear model, GLM) では, 目的変数の種類に合わせて確率分布を選び, その分布の平均を説明変数の一次式と関数で結び付けます. 久保 (2012, p. 6) は, データのばらつきを等分散の正規分布で表す線形モデルを, 正規分布以外の確率分布も扱えるように拡張したものとして一般化線形モデルを位置付けています. 同じ頁で, 線形モデルは確率分布を等分散の正規分布とした一般化線形モデルの一部だと述べています.

    本稿では, まず 0 か 1 の目的変数で, 線形回帰の当てはめ値が確率として読めないことを確かめます. そのうえで一般化線形モデルを構成する 3 つの要素を説明し, 個数や正の連続値を含めて, 目的変数の種類ごとに使う分布の一覧を示します. 最後に, 0 か 1 の目的変数に使うロジスティック回帰と, その係数の読み方を扱います.

    二値の応答の平均と確率

    最初に, 目的変数が 0 か 1 の 2 値をとる場合を考えます. 同じ時間だけ勉強し, 同じ時間だけアルバイトをする学生のうち, どれくらいの割合で単位を取得するのでしょうか.

    同じ条件の学生の平均

    学生の勉強時間とアルバイト時間をまとめて X と書きます. 単位を取得したかどうかを表す目的変数を Y とし, 取得したときは Y=1, 取得しなかったときは Y=0 とします. 例えば, 勉強時間とアルバイト時間がそれぞれ同じ学生 10 人のうち, 4 人が単位を取得したとします. 10 人の Y の平均は (4 \times 1 + 6 \times 0)/10 = 0.4 で, この 10 人の取得割合に等しくなります.

    母集団でも, 条件 X をそろえて考えます. Y が 1 と 0 をとる確率でそれぞれの値を重み付けすると, 条件つき期待値は次のようになります.

    \begin{aligned} E(Y \mid X) &= 1 \times P(Y=1 \mid X) + 0 \times P(Y=0 \mid X) \\ &= P(Y=1 \mid X). \end{aligned}

    したがって, 勉強時間とアルバイト時間が同じ学生の母集団での平均を推定することは, その条件の学生が単位を取得する確率を推定することです.

    線形回帰の当てはめ値の範囲

    上限が 4 点の GPA を一次式で予測すると, 予測値が 4 点を超えることがあります. GPA を予測した例では, テストデータの 1 人でこのような値が出ました. 単位の取得を 0 と 1 で記録したとき, 同じように一次式の値が範囲を外れると, その値を取得確率として読めるでしょうか.

    確率は 0 から 1 の間の値をとります. 一方, 勉強時間の一次式で取得確率を表すと, 傾きが 0 でない限り, 式の値をあらゆる勉強時間について 0 から 1 の間に収める仕組みはありません.

    練習用の架空のデータには, 学生 200 人について, 週あたりの勉強時間とアルバイト時間, ある科目の単位を取得したかどうかを記録しています. 次の図には, このデータに勉強時間だけを説明変数とする線形回帰を当てはめた結果を示します.

    観測値は縦軸の 0 と 1 の 2 本の線の上にだけあり, 勉強時間が長い学生ほど 1 の線の上に多くいます. 回帰直線の傾きは週 1 時間あたり約 0.077 です. 当てはめ値は観測した 200 人のうち 6 人で 0 未満, 15 人で 1 を超えます. 直線が 0 と交わるのは週約 1.15 時間, 1 と交わるのは週約 14.09 時間で, 6 人は 0 との交点より左側に, 15 人は 1 との交点より右側にいます.

    観測された勉強時間の範囲内でも確率として読めない値が出るため, 単位の取得を扱うモデルでは, 勉強時間の一次式と取得確率を, 値が 0 から 1 に収まる関数で結び付けます. どの関数を使うかは, 目的変数がどの分布に従うと考えるかによって決まります.
