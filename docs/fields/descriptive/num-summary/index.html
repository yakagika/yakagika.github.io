    データの数値化

    データを可視化することで, データの大まかな傾向はつかめます. しかし, グラフではデータの特徴を大まかにしか捉えることができません. データの特徴を具体的に述べるには, それを数値にする必要があります.

    例えば, 以下のヒストグラム (データ) を見てみましょう.

    ヒストグラム B と比較して, A はデータの中心が右にあり, データの散らばりが大きいように見えます. しかし, A の中心が B よりどの程度右にあり, A の散らばりがどの程度大きいのかは, グラフからは読み取れません. このように, グラフによる比較では, 抽象的な印象しか語ることができないため, データの中心や, 散らばりを数値で表すことが必要です.

    数値化の対象となる量は, 同時に扱う変数の数と, 各変数が量的か質的かで, おおよそ決まります. 下の樹形図を上から順にたどって, 求める数値を選んでください. 数値の名前をクリックすると, その統計量の解説に移動します.

    • データの数値化
      • 変数が 1 つ
        • 量的 → 分布が単峰で左右対称か
          • はい → 平均 と 標準偏差
          • いいえ (歪んでいる, 外れ値がある) → 中央値 と 四分位範囲
        • 質的 → 最頻値 と各カテゴリーの割合
      • 変数が 2 つ
        • 量的 × 量的 → ピアソンの積率相関係数
        • 順序 × 順序 → スピアマンの順位相関係数
        • 名義 × 質的 → \chi^2 統計量とクラメールの連関係数 V
      • 変数が 3 つ以上
        • 2 つずつの相関を一覧にする → 相関係数のヒートマップ
        • 3 つ目の変数の影響を除いて 2 つの関係を見る → 偏相関係数
        • 多数の変数をまとめて扱う → 回帰分析などの多変量解析

    平均と中央値のどちらを使うかは, 中心を表す代表値の使い分けで説明します.
