# 最初に全員で読む共通資料 {#first}

本科目では, LLM に分析のプログラムを書かせ, その結果を読んで確かめながら研究を進めます. そのための環境を, 他の講義と共通の資料で最初に用意します. 次の順に読んでください.

1. [プログラミング用の設定](/lectures/setup.html): VSCode とコマンドラインの設定, 基本コマンド.
2. [バージョン管理と GitHub](/lectures/git.html): 研究のコードと原稿の変更の履歴を記録し, 教員と共有する方法. LLM が加えた変更を差分で読む方法も扱います.
3. [コーディングエージェントの利用](/lectures/agent.html): **コーディングエージェント** (LLM が指示を受けて, ファイルの読み書きとコマンドの実行まで行う道具) の導入と操作, sandbox と承認の考え方.

コーディングエージェントの資料は OpenAI の codex を例に説明していますが, 本科目では Codex, Gemini, Claude のどれを使っても構いません. 料金と性能は短い期間で変わるので, どれを推奨するかはその時期に講義で伝えます. 契約の考え方はデータサイエンス実践と同じで, まず無料のアカウントで試し, 利用量の上限で作業が止まるようになったら有料の契約を検討します. 契約の時期と期間は講義中に案内します.

::: note

共通資料の演習には, 他の講義で課すものも含まれます. 本科目で行う演習は講義中に指示します.

:::

# 必要になったときに読む共通資料 {#later}

次の共通資料は, 研究の段階や学生の履修状況に応じて読みます.

- [プログラミング基礎](/lectures/python1.html) (全 5 章): データサイエンスのためのプログラミングを履修していない学生は, 最初の準備と並行して読みます. LLM に書かせたコードも, 研究に使うには自分で読んで説明できる必要があるからです ([LLM を研究に使う条件](material:llm#conditions)).
- [LaTeX による原稿作成](/lectures/latex.html): 論文を書く段階 ([論文と発表](material:writing)) で, 学会のテンプレートを使って原稿を書くときに読みます.
- [Google Colaboratory による GPU 計算](/lectures/colab.html): 手元の PC では分析の計算に時間がかかりすぎるときに読みます. Colaboratory は Google のサーバで計算するので, 個人に関わるデータを扱う分析には使いません ([セキュリティとデータの扱い](material:llm#security)).
