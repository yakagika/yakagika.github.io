# 1 年間の締切 {#deadlines}

本科目の成果物は論文で, 年度末までに学会で発表します ([1 年間の流れ](material:guide#schedule)). 希望する学生は, 夏休みに学内の奨学論文コンテストでも発表します. 学会での発表には, 多くの場合, 発表の申し込み, 原稿の提出, 発表の当日の 3 つの締切があります. 発表する学会とそれぞれの締切は年度によって変わるので, 講義中に案内します. [研究計画](material:plan#proposal)の予定の欄は, これらの締切から逆算して書きます.

# 論文の構成 {#structure}

論文の節は, 研究計画の項目と次のように対応します. 研究計画を書いた時点で, 序論と方法の材料の多くはそろっています.

| 論文の節 | 書く内容 | 対応する研究計画の項目 |
|---|---|---|
| 序論 | 問い, 先行研究の中での位置づけ, 目的 | 問い, 先行研究, 目的 |
| 方法 | データの集め方と性質, 分析の手法 | データ, 手法 |
| 結果 | 分析の結果を示す図と表 | |
| 考察 | 結果から言えることと言えないこと, 予想と比べて分かったこと, 中心の問いについて言えること | 予想, 問い |
| 結論 | 問いへの答えと, 残った課題 | 問い |
| 参考文献 | 本文で引用した文献 | 先行研究 |

考察で中心の問いについて書く理由は, [小さな問いを, データで答えられる形に書き直す](material:plan#data-question)にあります. 各節の書き方は講義で扱います.

# 原稿の書き方 {#manuscript}

原稿は, 学会が配布する LaTeX のテンプレートで書き, GitHub で教員と共有します. 手順は共通資料の[LaTeX による原稿作成](/lectures/latex.html)にあります.

原稿に LLM の出力を使って構いませんが, 中身を自分で制御できることが前提です. 確かめることは[論文と発表の原稿に使う](material:llm#manuscript)にあります. LLM に書かせた原稿は, 段落ごとの主張を 1 文ずつ抜き出して並べ, 主張が自分の分析の結果と一致しているか, 順序が問いから結論まで通っているかを確かめます.

# 発表の方法 {#presentation}

発表資料の作り方と口頭発表の方法は, 講義で扱います. 発表資料にも, 原稿と同じ条件で LLM の出力を使えます.
