## 問題

1. 約 550 MB をダウンロードして, 実際に使うのは 1,200 枚だけである. 通信量と手順が, 学ぶ内容に見合わない.
2. 学習に GPU が要る. GPU のない PC では長くかかり, Colab に移すにも, 画像の置き方に手間がかかる (`colab.md` では, 第 10 章のデータだけを例に挙げ, 第 9 章の年齢識別には触れていない).
3. 正解率が 0.417 で, 結果の解釈より先に「なぜ低いのか」の説明が必要になる.

## FairFace の再配布の可否 (2026-10-26 調査)

### 結論の要旨

**条件つき. 現時点では「教員が部分集合を配布してよい」と断定できない.** 著作権の面では, 元の画像が Creative Commons の Attribution (BY) か Attribution-ShareAlike (BY-SA) で公開されたものに限られ, 再配布と改変 (リサイズ) は許諾の範囲にある. ただし次の 3 点が未解決である.

1. 画像ごとの作者と元のライセンスが, FairFace の配布物に含まれない. 帰属表示 (作者名の表示) を画像ごとには果たせない.
2. 論文は元の画像を BY と BY-SA だと述べ, GitHub と Hugging Face は一括で CC BY 4.0 と表記する. 食い違っている. BY-SA の画像をリサイズして配るなら, その派生物は BY-SA で共有する条件が付く.
3. 画像に写る人の肖像・プライバシー・個人情報の扱いは, CC ライセンスの対象外である. 日本の大学での扱いは未確認.

現状の第 9 章 (学生が公式の配布元から各自ダウンロードする) は, 教員が再配布しないので, この問題の外にある. 案 A は, この 3 点を解消するか, 許容すると判断した場合にだけ進められる.

### 画像とラベルのライセンスの区別

| 対象 | 表記 | 出典 |
|---|---|---|
| FairFace の公式配布 (GitHub) | `License: CC BY 4.0` とだけ書かれている. リポジトリに LICENSE ファイルは無い (2026-10-26 時点で, リポジトリ直下は README.md のみ) | https://github.com/joojs/fairface |
| Hugging Face の配布 (HuggingFaceM4/FairFace) | メタデータは `license: cc-by-4.0`. データセットカードの「Licensing Information」は `[More Information Needed]`. 画像の出所は "Images were collected from the YFCC-100M Flickr dataset" | https://huggingface.co/datasets/HuggingFaceM4/FairFace |
| 論文 (Kärkkäinen & Joo, WACV 2021) の画像の出所 | "We only used images with "Attribution" and "Share Alike" Creative Commons licenses, which allow derivative work and commercial usages." / "This dataset was derived from the Yahoo YFCC100m dataset for images with Creative Common Licenses by Attribution and Share Alike, which permit both academic and commercial usage." | https://arxiv.org/abs/1908.04913 (PDF: https://arxiv.org/pdf/1908.04913) |
| YFCC100M (画像の供給元) | Flickr に CC ライセンス (商用可と非商用のどちらも) で公開された写真. 約 31.8% が商用利用に適したライセンス. 写真ごとのライセンスは元のまま | https://arxiv.org/abs/1503.01817 |

区別すると次のとおり.

- **ラベル (年齢・性別・人種の注釈) と, データセット全体の表記**: GitHub と Hugging Face が CC BY 4.0 と書く. ただし GitHub の README の `License: CC BY 4.0` が, 画像とラベルのどちらを指すのかは書かれていない (未確認).
- **画像そのもの**: 論文によれば, 元の Flickr 写真ごとの CC BY または CC BY-SA に従う. FairFace 側が一括で CC BY 4.0 と表記しても, 元が BY-SA の写真の条件は消えない (これは CC の法的条文からの推論で, FairFace の作者の見解は未確認).
- 論文は, 画像が BY と BY-SA のどちらかを画像ごとに区別して示していない. どの画像がどちらかは, 配布物からは分からない (配布のラベルの列は `file`, `age`, `gender`, `race`, `service_test` だけ. 本章の説明と Hugging Face の特徴量の定義で確認).
- 「非商用 (NC) の条件」: 論文は, 使った画像を BY と BY-SA に限ったと述べ, 商用利用も許すとする. 非商用限定の画像が混じるとは書かれていない. なお, 元の YFCC100M 全体には NC の写真が含まれる (上の表) が, FairFace はそれを除いたと論文は述べる. 検証はしていない (未確認).

### 条件の整理 (Creative Commons の条文)

出典: https://creativecommons.org/licenses/by/4.0/legalcode.en, https://creativecommons.org/licenses/by-sa/4.0/legalcode.en

| 論点 | 条文の内容 | この件への当てはめ |
|---|---|---|
| 再配布 | 共有 (Share) できる. 受け手に追加の制限を課してはならない ("You may not offer or impose any additional or different terms or conditions") | 学生への配布自体は許諾の範囲. LMS の利用規約で転載を禁じる程度の制限は, 追加条件にあたるかどうか未確認 |
| 帰属表示 (BY) | 作者の特定, 著作権表示, ライセンスへの言及, 免責への言及, 可能なら元の URI を残す. 方法は媒体と文脈に応じて「合理的な方法」でよく, リンク先に情報があればよい場合がある | 作者と元の URI は FairFace の配布物に無い. 元の Flickr の情報は YFCC100M のメタデータにあると思われるが, FairFace の画像との対応づけの手段は未確認 |
| 改変 | 改変したことを示す. 改変物 (Adapted Material) も条件に従う | リサイズ・切り出しは改変にあたる可能性が高い. 「改変した」と本文か配布物に書けば足りる |
| 継承 (SA) | BY-SA の画像の改変物を共有するときは, 同じ条件 (BY-SA か互換) で共有する | BY-SA の画像をリサイズして配るなら, 配布物の画像は BY-SA にする必要がある. BY の画像と混在するなら, 一括で BY-SA を表記すれば安全側だが, 本人が判断する |
| 肖像・プライバシー | "Publicity, privacy, and similar personality rights" は許諾の対象外 (権利者は限られた範囲で主張しないと述べるのみ) | 顔画像は個人を識別しうる. 配布して構わないかは, CC の許諾とは別に判断が要る. 未確認 |

### 大学の授業での配布の見立て

**教員が部分集合 (数百から数千枚, リサイズ済み) を LMS や GitHub で学生に配ってよいか: 断定できない.** 分かっていることと不明なことを分けて書く.

分かっていること.
- 論文が述べる画像の出所は BY と BY-SA で, 再配布と改変を許すライセンスである. 配布そのものを禁じる記述は, GitHub, 論文, Hugging Face のどこにも見つからなかった.
- 学生へ配るだけなら, 大学内の LMS でも公開の GitHub でも, CC の許諾の範囲としては同じ扱いになる. ただし公開の GitHub (このリポジトリは講義資料として公開されている) では, 学生以外にも配ることになり, 肖像・プライバシーの論点の重さが変わる. 学生に限る LMS の方が, 慎重な選択である.

不明なこと (誰に確かめるか).
1. 画像ごとの作者・ライセンスの帰属表示を, どの形で履行すれば足りるか. 確かめる相手は, FairFace の作者 (論文の連絡先. GitHub の issue でも可) と, 所属大学の著作権の担当窓口である. 作者に「画像ごとの元の Flickr の情報 (作者, ライセンス, URL) の対応表があるか」を尋ねるのが, 最も話が早い.
2. 一括の CC BY 4.0 の表記と, 元の BY-SA の画像との関係. 作者に尋ねる.
3. 授業での利用に, 日本の著作権法の教育機関の例外 (第 35 条) が使えるか. 使えるとしても, 本件は CC の許諾があるので, 例外に頼る必要があるかは別の問いである. 所属大学の著作権の担当窓口に確かめる (条文は未確認).
4. 顔画像の学生への配布が, 個人情報や肖像の観点で問題ないか. 所属大学の個人情報保護の担当窓口に確かめる (条文と大学の規程は未確認).
5. Flickr で作者が写真を削除したとき, 配った画像も消す義務があるか. 未確認 (YFCC100M の利用条件にあたる Yahoo Webscope の契約書は, 一次の文書に届かず未確認).

### 本文の記述への影響

第 9 章の本文 (`lectures/dsp/dsp9.md` の「顔による年齢識別」の冒頭) は, データセットが「CC BY 4.0 (出典を示せば再配布や改変ができるライセンス)」で公開されていると説明している. 論文は元の画像が BY と BY-SA だと述べているので, 画像の再配布や改変について, この説明は正確さに欠ける. 方針 (A, B, C) に関わらず, 本文の記述を直すか, 注を足す必要がある. 現状の本文では, 画像の出典の表示 (特徴マップと Grad-CAM の図の下) は, データセットの CC BY 4.0 と作者の名前だけで, 画像ごとの撮影者は示していない. これが帰属表示として足りるかも, 上の不明点 1 に含まれる.
