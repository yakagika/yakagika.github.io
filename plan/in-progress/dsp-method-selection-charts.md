## 候補の選定基準

1. 章の中に, 目的かデータの種類で使い分ける手法が 3 つ以上ある.
2. 分岐の問いが, 学生が手元のデータを見て答えられる (目的変数の種類, 尺度, クラスの偏りなど).
3. 行き先が章内の節 (か他章) にあり, リンクで飛べる.

## 候補

### 優先度 高

**A. 第2章 分析設計 (`様々なデータ分析手法` の 2 つの note を置き換える)**
本科目全体の入口. 今の note は「目的 → 手法」と「データの種類 → 手法」を別々に列挙しているので, 1 つの樹形図にまとめる. 行き先は各章.

- 何を明らかにしたいか
  - 2 つの変数に関係があるか → 相関 (第4章)
  - グループの間に違いがあるか → 検定 (本科目の範囲外. 統計学の科目へ)
  - ある変数を他の変数から説明・予測したい → 目的変数の種類
    - 量的 → 線形回帰 (第5章)
    - カテゴリー (0/1 を含む) → 分類 (第6章)
    - 個数・割合, 個体差がある → 一般化線形モデル (第12章 → 繰り下げ後 第13章)
  - データをグループに分けたい, 少数の軸に要約したい → クラスタリング (第7章), 次元削減・因子分析 (第13章 → 第14章)
  - 一緒に起きる組み合わせを見つけたい → アソシエーション分析 (第7章)
- データの種類で章が決まる場合
  - 文章 → 自然言語処理 (第9章) / 画像 → 画像認識 (第10章 → 第11章) / 質問紙の回答 → 第13章 (→ 第14章) / 欠損がある → 欠損値補定 (第14章 → 第15章)

**B. 第4章 データの数値化 (`#basic-stats` の前か, 冒頭の表を置き換える)**
冒頭の表 (データの数 × 種類 → 求める数値) と, 相関の節の表 (尺度 × 尺度 → 係数) を 1 つにまとめる.

- 変数は 1 つか 2 つか
  - 1 つ
    - 量的 → 分布は左右対称で, 外れ値が少ないか → はい: 平均と標準偏差 / いいえ: 中央値と四分位範囲
    - 質的 → 最頻値と割合
  - 2 つ
    - 量的 × 量的 → ピアソンの積率相関係数 (第 3 の変数の影響を除くなら偏相関係数, 発展)
    - 順序 × 順序, または外れ値が多い量的 → スピアマンの順位相関係数
    - 名義 × 質的 → クロス表と χ² 統計量 → クラメールの連関係数 V
- 3 つ以上 → 多変量解析 (第5章以降)

**C. 第13章 質問紙調査 (→ 第14章) (`データ処理` の前)**
質問項目の種類から分析を選ぶ.

- 項目の回答の形式
  - 単一選択 × 単一選択 → クロス表 → 独立性の検定 → 有意なら残差分析
  - 複数選択 → 選択肢ごとの 0/1 の列に分けてから集計
  - リッカート尺度 (段階評価) → ヒストグラム, 相関係数 (順序として扱うならスピアマン)
  - 複数の項目で 1 つの態度を測る → 信頼性 (クロンバッハの α) → 共分散構造分析 (SEM)

**D. 第6章 機械学習の枠組みと決定木 (`分類の評価` の冒頭)**
評価指標の選び方. 学生が最も迷う箇所で, 章内に指標の節が揃っている.

- 予測するのは量的な値か, カテゴリーか
  - 量的 → 回帰の評価 (第5章 `回帰の評価`)
  - カテゴリー → クラスの割合が大きく偏っているか
    - いいえ → Accuracy
    - はい → 何を避けたいか
      - 見逃し (陽性を陰性と予測) → Recall
      - 誤検知 (陰性を陽性と予測) → Precision
      - 閾値を決めずにモデルどうしを比べる → ROC 曲線と AUC

### 優先度 中

**E. 第7章 クラスタリングとパターン発見 (冒頭)**
- 何を見つけたいか
  - 一緒に買われる組み合わせ → アソシエーション分析 (支持度, 確信度, リフト値)
  - 似た会員のグループ
    - グループの数を決めて分けたい, データが多い → k-means 法 (数はエルボー法, シルエット係数で選ぶ)
    - 併合の過程を見て数を決めたい, データが少ない → 階層クラスタリング
    - 丸くない形, 外れ値がある → DBSCAN (発展)
    - グループが重なり合う → 混合ガウスモデル (発展)

**F. 第12章 一般化線形モデル (→ 第13章) (`一般化線形モデル (GLM)` の節)**
目的変数の種類から確率分布とリンク関数を選ぶ. 章の実習は正規分布 + 個体差なので, 他の分布は行き先の節が無く, 名前だけになる.
- 量的で対称 → 正規分布 + 恒等リンク (線形回帰) / 個数 → ポアソン分布 + 対数リンク / 0/1, 割合 → 二項分布 + ロジットリンク / 個体ごとのばらつきが大きい (過分散) → 個体差を入れる

**G. 第9章 自然言語処理 (冒頭)**
- やりたいこと
  - よく出る語を知りたい → 形態素解析と集計, ワードクラウド (専門語が分割されるならユーザ定義辞書)
  - 誰が何をしたかを取り出したい → 係り受け解析
  - 文章をカテゴリに分けたい → ニューラル言語モデル (マルチラベル分類)

### 入れない章

- 第1章 (読み方), 第8章 (仕組みの説明で, 選ぶ手法が無い), 第11章 総合実習 (題材は 3 つで, 要綱の表で足りる).
- 第5章 線形回帰: 単回帰か重回帰かは説明変数の数で決まるだけ. 回帰か分類か GLM かは A に入れる.
- 第10章 画像認識: 手法は章の中で順に発展する (特徴量 → ニューラルネットワーク → CNN → ViT) ので, 選ぶ形にならない.

## 本人の判断が要る点

1. **追加する章**: A〜D (優先度 高) だけか, E〜G も入れるか.
2. **図の形式**:
   - HTML の樹形図 (第3章の形): 行き先をクリックで飛べる, ダークモードで色が合う, 文字の修正が md の編集で済む. 第3章の `<style>` を `css/base.css` の共通の class に移し, 各章は入れ子のリストだけを書く形にする (今は第3章だけに style がある).
   - PNG の流れ図 (第14章の形): はい/いいえの順の問いを見せやすい. リンクは図の下の一覧で補う. 修正のたびに作図し直す.
   - 案: 目的やデータの種類で枝分かれする A, B, C, E, G は樹形図, はい/いいえの順の問いになる D は流れ図. 第14章を樹形図に揃えるかも合わせて決める.
3. **作業の順**: 章番号の繰り下げ (dsp-transformer-training-chapter) の後にする. 繰り下げは全章の `dspN.html` を置き換えるので, 先にチャートを入れると置き換えの対象が増え, 同時に進めると衝突する.
