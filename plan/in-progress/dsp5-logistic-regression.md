## 設計

### 節の構成 (第5章の「説明変数の組み合わせをテスト MSE で比べる (発展)」の後, 「実データでの事例」の前)

`## 一般化線形モデル: ロジスティック回帰 (発展) {#logistic-regression}`

1. 目的変数が 2 値のとき, 線形回帰を当てはめると予測値が 0 未満や 1 超になる問題を, 合成データの散布図と回帰直線で示す.
2. 一般化線形モデルの 3 つの要素 (確率分布, 線形予測子, リンク関数) を, 線形回帰 (正規分布 + 恒等リンク) とロジスティック回帰 (ベルヌーイ分布 + ロジットリンク) の 2 列の表で並べる. 数式と Python のコードを並べて対応を示す.
3. ロジスティック関数 (S 字の曲線) とオッズ, 対数オッズの関係. 係数は「説明変数が 1 増えたときの対数オッズの増分」, $\exp(\beta)$ はオッズ比として読む.
4. statsmodels の `sm.Logit` (または `sm.GLM(..., family=sm.families.Binomial())`) で推定し, 係数, p 値, オッズ比を読む. 推定は最小二乗法でなく最尤法で行うことを 1 段落で述べ, 尤度の説明は第13章の該当節へリンクする.
5. 予測確率の曲線を散布図に重ねる図.
6. 予測確率をしきい値 0.5 で分類に使えること, 分類の評価は第6章へリンクする (第11章と第16章で使う手法であることにも触れる).

演習は足さない (発展の節から演習へリンクしない規約).
