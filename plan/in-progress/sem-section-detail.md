## 背景

現行の節は「SEM は回帰分析と因子分析を同時に行う」と要約するだけで, 何を推定しているのかが書かれていない
(ユーザ評価 2026-09-30). 点検で見つかった問題:

1. 中心の仕組み (モデルが共分散行列 Σ(θ) を予言し, 標本の S と突き合わせる) が一度も説明されない.
2. 測定モデルと構造モデルの区別がなく, 「構造モデル」をモデル全体の意味で使っている.
3. 回帰式に係数も誤差項もない. 因子分析の式 `脚力 = 100M + 走り幅跳び` は向きが逆 (合成変数の向き).
   同じ節の図 sem-1.png は正しい向き.
4. 識別 (負荷量の 1 固定) と自由度 (DoF 27 = 55 − 28) の説明がない. `~~` の行 (残差分散・因子の共分散) も説明がない.
5. 本文とコードの不一致: 本文と図 sem-4.png は Office (Q16) を含むが, モデルは使っていない.
6. 結果の読み違い: 有意でないのは creation → Smartphone のパスなのに, 本文は「スマホの興味関心から情報作成志向」と書く.
7. 適合の判定が甘い: χ² p=0.000, RMSEA 0.093, GFI 0.948, TLI 0.919 なのに「適合性が確認された」,
   図 sem6.png に「仮説がわりとちゃんと立証」. 横断データで因果を立証したかのような記述.
8. `inspect()` の既定出力は非標準化推定値 (IT の負荷量 1.276). 係数の大小比較には `std_est=True` が要る.
9. 適合度の表: RMSEA を「一人一人の観測値に対して」と誤記. slds 側は χ² の向きの逆転などの誤記が残る (dsp 側は修正済).
10. コード: `stats = semopy.calc_stats(mod)` が scipy の `stats` を上書きする.
11. **前処理のバグ** (`to_list`): 「どれも身に付いていない」(Q12, Q16) と「どれもしらない」(Q9) が照合に漏れ,
    該当者が 0 個でなく 1 個と数えられる. Q16 は 838 人が該当. SEM の結果への影響は小さい (Q9 のみモデルに入る, 係数は 3 桁目で変化).

## 設計

### A. 説明の節 (両講義で同文)

1. 因子モデルを式で示す: x_i = λ_i ξ + δ_i. 負荷量, 独自因子, 章前半の共通性・独自性との対応.
   100M は負の負荷になることに触れる.
2. 構造の部分を回帰式で示す: η = γ_1 ξ_1 + γ_2 ξ_2 + ζ. 測定モデルと構造モデルの語をここで定義する.
3. 共分散の構造: 1 因子 3 指標の小さな例で Var(x_i)=λ_i²φ+θ_i, Cov(x_i,x_j)=λ_iλ_jφ を導き,
   「モデルが共分散行列を予言する」ことを示す. 数値例を numpy で確かめる短いコードを付ける.
4. 識別と自由度: λ_1=1 の固定, 自由度 = p(p+1)/2 − (推定するパラメータ数). 実例の 55 − 28 = 27 と対応させる.
5. 推定: 最尤法で S と Σ(θ) の食い違い F を最小にする. χ² = (N−1)F_min.
6. 適合度: 表を作り直す (χ², RMSEA, SRMR, CFI, TLI, GFI/AGFI). χ² は N が大きいとほぼ必ず棄却されることを明記.
7. 因果について: SEM が確かめるのは仮説とデータが矛盾しないことであり, 横断データで因果を立証するものではない.

### B. 実例

1. 仮説の図 (sem-4.png) とモデル式を一致させる. Office は外し, 本文からも外す.
2. 前処理の `to_list` を「どれも」で始まる回答すべてを 0 個にする形へ直す (範囲は下記 §未決).
3. `inspect(std_est=True)` で標準化推定値を出し, 出力の各行 (`~`, `=~` に当たる行, `~~` の行) の読み方を説明する.
4. 適合度を率直に評価する (グレーゾーン).
5. 残差相関を出して, どこがモデルに合っていないかを見る → Windows を knowledge にも負荷させる改良モデル.
   データを見てモデルを直すことの危険 (同じデータでの検証は甘くなる, 理論的な理由づけが要る) を明記する.
6. 改良で PC ← creation の結論が消えることを示し, 「結論はモデルに依存する」を締めにする.
7. `stats` の上書きを直す.
