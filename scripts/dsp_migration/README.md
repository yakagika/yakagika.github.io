# 旧データサイエンス実践の移行記録

旧 dsp のページから分野別の参考資料と講義専用ページを作ったときの対応表です. 現在は参考資料を正本として直接編集するため, 変換スクリプトは撤去しました. スクリプトはコミット `4219e68` のこのディレクトリにあります.

- `layout.tsv` は旧章の範囲と演習を, 移行先のブロックに対応づけます.
- `page_ids.tsv` は旧章の見出し ID を, 移行先のページ ID に対応づけます.
- `added_links.tsv` は変換時に追加したリンクの位置, 表示名, 行き先を記録します.
- `requires_review.tsv` は各ブロックの前提となるブロックの現行指定, 変更案, その根拠を記録します.
