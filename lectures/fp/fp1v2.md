# はじめに

本講義では, 関数型プログラミング言語 Haskell の基礎と使い方, そしてプログラムの設計を扱います. 想定する履修者は, Python などの手続き型言語を使ったことはあるが, 関数型言語は初めてという学部生です. 集合論や代数学の予備知識は前提にせず, 必要なものは初歩から導入します. ただし数学そのものの習得は目的ではないので, 説明は講義に必要な範囲に絞ります.

本章ではまだ Haskell を使いません. Haskell を動かす環境は[第2章](fp2.html)で整えます. 本章で使う道具は紙と鉛筆だけです. 題材はじゃんけんと図書館の貸出という身近な 2 つの規則で, どちらも日本語で説明できるつもりになっているものです. その説明を書き出してみると, 答えられない問いがすぐに見つかります. 答えられない問いに答えられるよう, 規則を **対象**, **操作**, **法則** の 3 つに分けて書き直し, 書き直した規則が正しいかを反例を探して確かめます. 以後の章で Haskell を学ぶ理由は, この「分けて書き, 反例で確かめる」作業を機械に手伝わせることにあります.

# 自然言語の規則が答えられない問い

じゃんけんのルールを, じゃんけんを知らない人に説明するとします. 多くの人は次のように書くでしょう.

::: note
グーはチョキに勝ち, チョキはパーに勝ち, パーはグーに勝つ. 2 人が同じ手を出したらあいこで, やり直す.
:::

これで十分に説明できたように感じます. しかし, この説明を読んだ人から「3 つの手のうち一番強いのはどれですか」と聞かれると, 答えに詰まります. 「グーはチョキより強い」「チョキはパーより強い」と言えるのなら, 「グーはパーより強い」とも言えそうですが, 説明の 3 文目にはパーがグーに勝つと書いてあります. 「強い」という日常語には順位の意味が含まれていて, その意味がじゃんけんの勝敗とは合わないのです. 説明の文面にはどこにも誤りがないのに, 読み手が持ち込んだ順位の意味によって, 規則についての問いに答えられなくなっています.

図書館の貸出の規則でも同じことが起こります.

::: note
利用者は本を借りることができ, 借りた本を返却する. 1 人が借りられる本は 5 冊まで. 貸出中の本は借りられない.
:::

この説明からは, 次の問いに答えられません.

- 6 冊目を借りようとした利用者には何が起こるのか. 借りられないのか, 1 冊目が自動的に返却されるのか.
- 誰も借りていない本を「返却」したら何が起こるのか.
- 同じ利用者が, 同じ本をもう一度借りることはできるのか.

どちらの説明も, 書いた本人は「記述できた」と感じます. 書いた本人の頭の中では, 説明に書かれていない部分が常識で補われているからです. ところが, 規則を他人に渡したり, 規則どおりに動く仕組み (プログラム) を作ったりする段階になると, 補われていた部分が人によって違うことが表に出ます. 規則を厳密に書けないうちは, その規則を他人と同じ意味で理解しているとは言えず, 規則を組み合わせたり変更したりする操作も, 規則が守られているかを確かめる制御もできません.

本章の残りでは, 2 つの規則を次の手順で書き直します.

1. 規則が扱うものの集まり (**対象**) を決める.
2. 対象の間の関係や, 対象を変える **操作** を決める.
3. 操作や関係が満たすべき性質 (**法則**) を書く.
4. 法則が成り立たない具体例 (**反例**) を探して, 書いたものを確かめる.

# じゃんけんの勝敗

## 勝敗を関係として書く

最初に対象を決めます. じゃんけんで出せる手の集合を $H$ とします.

$$
H = \{\text{グー}, \text{チョキ}, \text{パー}\}
$$

次に, 「$x$ は $y$ に勝つ」という勝敗を書きます. 2 人が出す手の組 $(x, y)$ は, $H$ の要素を 2 つ並べた組の集合, すなわち **直積** (direct product)

$$
H \times H = \{(x, y) \mid x \in H, y \in H\}
$$

の要素です. $H$ が 3 つの要素を持つので, 組は $3 \times 3 = 9$ 通りあります. この 9 通りの組それぞれについて, $x$ が $y$ に勝つかどうかを表にすると次のようになります.

| $x \backslash y$ | グー | チョキ | パー |
| :---: | :---: | :---: | :---: |
| グー | | 勝つ | |
| チョキ | | | 勝つ |
| パー | 勝つ | | |

勝つ組だけを集めると, 9 通りのうち 3 つの組からなる集合ができます.

$$
W = \{(\text{グー}, \text{チョキ}), (\text{チョキ}, \text{パー}), (\text{パー}, \text{グー})\} \subseteq H \times H
$$

このように, 直積の部分集合として表したものを **関係** (relation) と呼びます. $(x, y) \in W$ を「$x$ は $y$ に勝つ」と読み, $x \mathrel{W} y$ とも書きます. 日本語の説明では「勝つ」は動詞でしたが, 関係として書くと, 勝敗は 3 つの組からなる 1 つの集合になります. 集合になれば, 「勝敗という規則がどんな性質を持つか」を, 集合についての問いとして立てられます.

関係 $W$ について, 次の 3 つの性質は成り立ちます.

- **非反射律**: どの手も自分自身には勝たない. すなわち, すべての $x \in H$ について $(x, x) \notin W$.
- **非対称律**: $x$ が $y$ に勝つなら, $y$ は $x$ に勝たない. すなわち, $(x, y) \in W$ ならば $(y, x) \notin W$.
- **全域比較可能性**: 異なる 2 つの手なら, どちらかが勝つ. すなわち, $x \neq y$ ならば $(x, y) \in W$ か $(y, x) \in W$ のどちらかが成り立つ.

どの性質も, 表を見れば確かめられます. 非反射律は表の対角線に「勝つ」が無いこと, 非対称律と全域比較可能性は, 対角線を挟んで向かい合う 2 つのマスのちょうど一方にだけ「勝つ」があることに当たります.

## 推移律と順位

[自然言語の規則が答えられない問い](#自然言語の規則が答えられない問い)で詰まった「一番強い手」は, 関係の性質としては次の **推移律** (transitivity) が成り立つかという問いになります.

$$
(x, y) \in W \text{ かつ } (y, z) \in W \text{ ならば } (x, z) \in W
$$

推移律は「すべての $x, y, z$ について」成り立つことを主張する法則です. したがって, 成り立たないことを示すには, 前提を満たすのに結論を満たさない $(x, y, z)$ を 1 つ挙げれば十分です. このような具体例を **反例** (counterexample) と呼びます. $W$ には反例があります.

$$
(\text{グー}, \text{チョキ}) \in W, \quad (\text{チョキ}, \text{パー}) \in W, \quad \text{しかし} \quad (\text{グー}, \text{パー}) \notin W
$$

これと比べるために, 徒競走の着順を考えます. 3 人の走者 $a, b, c$ がこの順にゴールしたとき, 「$x$ は $y$ より先にゴールした」という関係

$$
F = \{(a, b), (b, c), (a, c)\}
$$

も, 非反射律, 非対称律, 全域比較可能性を満たします. $W$ との違いは推移律だけです. $F$ では $(a, b)$ と $(b, c)$ から $(a, c)$ が導かれ, 推移律が成り立ちます. 非反射律, 推移律, 全域比較可能性を満たす関係を **狭義の全順序** (strict total order) と呼び, 狭義の全順序があるときに限り, 対象を 1 列に並べる順位が付けられます. 推移律が成り立たない $W$ では, グー, チョキ, パーが輪になって勝敗が循環しているので, 順位は付けられません. 「一番強い手」という問いに答えられなかったのは, 説明が不足していたからではなく, 勝敗の関係が狭義の全順序ではないからです.[^order]

法則が成り立つことを確かめるには, すべての場合を調べる必要があります. 推移律なら, $x, y, z$ の選び方は $3 \times 3 \times 3 = 27$ 通りで, 手で調べられる数です. 対象の数が増えると手では調べきれなくなります. その段階で, 調べる作業をプログラムに任せることになります.

::: note

### Exercise CH1-1

**4 つの手のじゃんけん**

グー, チョキ, パーに 4 つ目の手を加えて, 4 つの手のじゃんけんを作ります. 勝敗の関係には, 本文の非反射律, 非対称律, 全域比較可能性を課します.

1. 4 つの手のどれもが, 同じ数の手に勝つ (どの手も他の手より有利にならない) ように勝敗を決められるかを答えてください. 決められないなら, その理由を説明してください.
2. 手を 5 つにした場合について, 同じ問いに答えてください. 決められるなら, 勝敗の表を書いてください.
3. 2. で作った勝敗の関係について, 推移律の反例を 1 つ挙げてください.

<details class="protected" data-pass="yakagika">
    <summary> 回答例 </summary>

1. 決められません. 異なる 2 つの手の組は $\{x, y\}$ の選び方だけあり, 4 つの手からは $4 \times 3 / 2 = 6$ 組です. 全域比較可能性と非対称律から, どの組でもちょうど一方が勝つので, 勝ちの総数は 6 です. 4 つの手がどれも同じ数 $k$ だけ勝つなら $4k = 6$ ですが, これを満たす整数 $k$ はありません.

2. 決められます. 5 つの手からは $5 \times 4 / 2 = 10$ 組なので, $5k = 10$ より各手が $k = 2$ 個の手に勝てばよいことになります. 手を $h_0, h_1, h_2, h_3, h_4$ とし, 各 $h_i$ が $h_{i+1}$ と $h_{i+2}$ に勝つ (添字は 5 で割った余りで数え, $h_5 = h_0$, $h_6 = h_1$ とする) と決めると, 次の表になります.

| $x \backslash y$ | $h_0$ | $h_1$ | $h_2$ | $h_3$ | $h_4$ |
| :---: | :---: | :---: | :---: | :---: | :---: |
| $h_0$ | | 勝つ | 勝つ | | |
| $h_1$ | | | 勝つ | 勝つ | |
| $h_2$ | | | | 勝つ | 勝つ |
| $h_3$ | 勝つ | | | | 勝つ |
| $h_4$ | 勝つ | 勝つ | | | |

3. $h_0$ は $h_2$ に勝ち, $h_2$ は $h_4$ に勝ちますが, $h_0$ は $h_4$ に勝ちません ($h_4$ が $h_0$ に勝ちます). 一般に, 手が 2 つ以上あるとき, どの手も同じ数の手に勝つ関係では推移律は成り立ちません. 推移律が成り立つなら狭義の全順序になり, 順位が 1 位の手はすべての手に勝ち, 最下位の手はどの手にも勝たないので, 勝ち数がそろわないからです.

</details>

:::

[^order]: 後の章では, 「以下」の形の関係 (反射律, 反対称律, 推移律, 全域比較可能性を満たすもの) を全順序と呼びます. 数の $<$ と $\le$ の違いに当たり, どちらで書いても順位が付けられるかどうかは変わりません.

# 図書貸出の規則

## 状態と操作

じゃんけんの勝敗は, 一度決めれば変わらない規則でした. 図書館の貸出では, 本を借りたり返したりするたびに「誰がどの本を借りているか」が変わります. このように, 操作によって変わっていく情報を **状態** (state) と呼びます. 図書貸出の規則を書き直すには, 対象と状態と操作を分けて書く必要があります.

対象は, 本の集合 $B$ と利用者の集合 $U$ です. 状態は, 「本 $b$ を利用者 $u$ が借りている」という組 $(b, u)$ を集めた集合 $L$ で表します.

$$
L \subseteq B \times U
$$

貸出の状態は, じゃんけんの勝敗と同じく, 直積の部分集合すなわち関係です. 違いは, $W$ が固定されていたのに対し, $L$ は操作のたびに別の集合に置き換わることです.

操作は「借りる」と「返す」の 2 つです. それぞれ, 操作を行ってよい条件 (**前提条件**) と, 操作の後の状態 $L'$ を書きます.

- $\text{借りる}(u, b)$:
    - 前提条件: 本 $b$ を借りている利用者がいない. かつ, 利用者 $u$ が借りている本が 5 冊未満である.
    - 操作の後の状態: $L' = L \cup \{(b, u)\}$.
- $\text{返す}(b)$:
    - 前提条件: 本 $b$ を借りている利用者 $u$ がいる. すなわち, ある $u$ について $(b, u) \in L$.
    - 操作の後の状態: $L' = L \setminus \{(b, u)\}$.

[自然言語の規則が答えられない問い](#自然言語の規則が答えられない問い)で挙げた 3 つの問いには, この書き方で答えが決まります. 6 冊目を借りる操作と, 誰も借りていない本を返す操作は, 前提条件を満たさないので行えません. 同じ本をもう一度借りる操作も, 本 $b$ を借りている利用者 (本人) がいるので行えません. ここで決めた答えが唯一の正解というわけではありません. 6 冊目を借りると 1 冊目が自動的に返却される規則を作ることもできます. 大事なのは, どの答えを採るかが仕様として書かれ, 読み手によって答えが変わらなくなったことです.

## 不変条件と反例

貸出の状態 $L$ には, どの時点でも成り立っていてほしい性質があります. このような性質を **不変条件** (invariant) と呼びます. 図書貸出の不変条件は次の 2 つです.

- **(I1) 1 冊の本を借りているのは高々 1 人**: $(b, u) \in L$ かつ $(b, v) \in L$ ならば $u = v$.
- **(I2) 1 人が借りている本は 5 冊まで**: すべての $u \in U$ について, $\lvert \{ b \mid (b, u) \in L \} \rvert \le 5$.

ここで $\lvert S \rvert$ は集合 $S$ の要素の個数を表します. 不変条件があると, 操作が満たすべき法則を書けます.

- **(L1) 操作は不変条件を保つ**: 不変条件を満たす状態から, 前提条件を満たす操作を行うと, 操作の後の状態も不変条件を満たす.
- **(L2) 借りてすぐ返すと元に戻る**: 状態 $L$ で $\text{借りる}(u, b)$ の前提条件が満たされるなら, $\text{借りる}(u, b)$ の直後に $\text{返す}(b)$ を行った状態は $L$ に等しい.

前提条件は, 法則 (L1) が成り立つように選んだものです. このことは, 前提条件を外すと反例が作れることで確かめられます. $\text{借りる}$ の前提条件から「本 $b$ を借りている利用者がいない」を外したとします. 本 $b_1$ を利用者 $u_1$ が借りている状態

$$
L = \{(b_1, u_1)\}
$$

は (I1) と (I2) を満たします. この状態で利用者 $u_2$ が本 $b_1$ を借りると,

$$
L' = \{(b_1, u_1), (b_1, u_2)\}
$$

となり, (I1) が成り立ちません. これが, 前提条件を外した規則に対する (L1) の反例です. 自然言語の規則の「貸出中の本は借りられない」という一文は, (I1) を保つために必要な前提条件だったことが, 反例によって分かります.

不変条件 (I1) を満たす関係 $L$ は, 各本 $b$ に対して, その本を借りている利用者を高々 1 人に決めます. 関係のうち, 1 つの左側の要素に右側の要素が高々 1 つしか対応しないものは, 後の章で関数を定義するときの出発点になります.

::: note

### Exercise CH1-2

**履修登録の規則を書いて反例を出す**

2 人から 4 人の班で行います.

1. 各班で, 大学の履修登録の規則を日本語で 3 文から 5 文で書いてください. 授業の定員や, 時間割の重なり, 登録できる単位数の上限など, 実際の履修登録で気になる点を含めてください.
2. 別の班と規則を交換し, 相手の規則では答えが決まらない問い, または相手の規則に従うと困った状態になる具体例を, できるだけ多く挙げてください.
3. 自分の班の規則を, 対象, 状態, 操作 (前提条件と操作の後の状態), 不変条件に分けて書き直してください. 2. で相手の班から挙げられた問いに, 書き直した規則で答えが決まることを確かめてください.

<details class="protected" data-pass="yakagika">
    <summary> 回答例 </summary>

1. の例: 「学生は授業を履修登録できる. 各授業には定員があり, 定員を超えた登録はできない. 同じ時限の授業は 2 つ以上登録できない. 1 学期に登録できるのは 24 単位まで.」

2. の例: 定員に空きが 1 人分あるときに 2 人が同時に登録したらどうなるのか. 登録を取り消せるのか. 取り消せるなら, 取り消した学生がもう一度同じ授業に登録できるのか. 2 つの時限にまたがる授業は, 他の授業とどう重なると判定されるのか.

3. の例:

- 対象: 学生の集合 $S$, 授業の集合 $C$. 各授業 $c$ には定員 $\mathrm{cap}(c)$, 単位数 $\mathrm{cr}(c)$, 開講する時限の集合 $\mathrm{slot}(c)$ が決まっている.
- 状態: 登録の記録 $R \subseteq S \times C$. $(s, c) \in R$ は「学生 $s$ が授業 $c$ に登録している」と読む.
- 操作:
    - $\text{登録}(s, c)$. 前提条件: $(s, c) \notin R$. 授業 $c$ の登録者数が $\mathrm{cap}(c)$ 未満. $s$ が登録しているどの授業 $d$ についても $\mathrm{slot}(c) \cap \mathrm{slot}(d) = \emptyset$. $s$ の登録単位の合計に $\mathrm{cr}(c)$ を足しても 24 以下. 操作の後の状態: $R' = R \cup \{(s, c)\}$.
    - $\text{取消}(s, c)$. 前提条件: $(s, c) \in R$. 操作の後の状態: $R' = R \setminus \{(s, c)\}$.
- 不変条件: 各授業の登録者数は定員以下. 各学生の登録単位の合計は 24 以下. 同じ学生が登録している異なる 2 つの授業の時限は重ならない.

「同時に登録したら」という問いには, 操作は 1 つずつ順に行われ, 2 人目の登録は前提条件を満たさないので行えない, と答えが決まります. 取り消した授業への再登録は, $\text{取消}$ の後に $(s, c) \notin R$ となるので, 他の前提条件を満たせば行えます. 2 つの時限にまたがる授業は $\mathrm{slot}(c)$ が 2 つの時限を含むことで表され, どちらかの時限が重なれば登録できません.

</details>

# 対象・操作・法則への分解

2 つの例で行った書き直しを並べると, 次の表になります.

| | じゃんけん | 図書貸出 |
| :---: | :--- | :--- |
| 対象 | 手の集合 $H$ | 本の集合 $B$, 利用者の集合 $U$ |
| 関係・状態 | 勝敗 $W \subseteq H \times H$ (固定) | 貸出 $L \subseteq B \times U$ (操作で変わる) |
| 操作 | なし | $\text{借りる}(u, b)$, $\text{返す}(b)$ |
| 法則 | 非反射律, 非対称律, 全域比較可能性. 推移律は不成立 | 不変条件 (I1), (I2). (L1), (L2) |
| 反例 | 推移律に対する (グー, チョキ, パー) | 前提条件を外した $\text{借りる}$ に対する $L = \{(b_1, u_1)\}$ |

2 つの例の違いは, じゃんけんでは関係を取り出して性質を調べ, 図書貸出では操作と不変条件を書いて操作が不変条件を保つかを調べたことです. どちらの例でも, 使った道具は集合, 直積, 部分集合だけでした. そして手順は同じです. 曖昧な日本語の規則から対象を取り出し, 関係や操作を決め, 法則を書き, 反例を探しました.

反例を探すのは, 法則が「すべての場合に成り立つ」と主張する文だからです. 法則を書いただけでは, それが正しいかは分かりません. 反例が 1 つ見つかれば, 法則が成り立たないこと, または規則のどこかに誤りがあることが確定します. 反例が見つからないうちは, 法則が成り立つ見込みが高まるだけです. すべての場合を調べ尽くしたときに初めて, 法則が成り立つと言えます. じゃんけんの推移律では 27 通り, 図書貸出の (L1) では本と利用者を少数に限った状態のすべてを調べれば, 手でも確かめられます.

日本語で書いた規則が無駄になるわけではありません. 規則を作る人が何を望んでいるかを集める段階では, 日本語が最も使いやすい道具です. 日本語の規則を対象・操作・法則に分けて書き直すと, 他人が同じ意味で読めるようになり, 他人が反例を出して規則の誤りを指摘できるようになります.

# 数学と型と Haskell を使う理由

対象・操作・法則に分けて書き, 反例で確かめる作業を, 本講義は数学, 型, Haskell の 3 つの道具で支えます.

1 つ目は数学です. 集合, 直積, 関係, 写像は, 対象・操作・法則を書くための共通の語彙です. 本章では集合と関係を断りなく使いましたが, 後の章で一つずつ定義し直します.

2 つ目は **型** (type) です. 型は, プログラムが扱う値の集合を宣言したものです. 手の集合 $H$ を型として宣言すると, 4 つ目の手のような, 規則に無い値はプログラムに書けなくなります. 規則に合わないものを書けなくすることで, 確かめるべき場合の数を減らせます.

3 つ目は Haskell です. Haskell は **静的型付けの純粋関数型言語** で, 関数を数式の等式とほぼ同じ形で定義できます. そのため, 本章で紙に書いた関係や操作を, ほとんどそのままの形で実行できるプログラムにできます. さらに, 法則を Haskell の式として書けば, すべての場合を機械に調べさせたり (全数検査), ランダムに作った多数の例で反例を探させたり (性質検査) できます. 本章で手で行った反例探しは, この 2 つの検査で機械化されます.

本章の 2 つの例は, 後の章で Haskell のプログラムとして書き直します. 手の集合や貸出の状態は[第5章](fp5.html)のデータ型として, 勝敗の関係と推移律の検査は[第6章](fp6.html)の関係として登場します. その前に, [第2章](fp2.html)で Haskell の実行環境を整えます.

### Exercise CH1-3

**総当たり戦の順位**

4 つのチーム $A, B, C, D$ が総当たり戦 (どの 2 チームも 1 回ずつ対戦し, 引き分けは無い) を行い, 次の結果になりました.

- $A$ は $B$, $C$ に勝ち, $D$ に負けた.
- $B$ は $C$, $D$ に勝った.
- $C$ は $D$ に勝った.

「$x$ は $y$ に勝った」という関係を $V$ とします.

1. $V$ を直積 $\{A, B, C, D\} \times \{A, B, C, D\}$ の部分集合として書いてください.
2. $V$ が推移律を満たすかを答えてください. 満たさないなら反例を 1 つ挙げてください.
3. 勝った試合の数 (勝ち数) で順位を付けたとき, 1 位のチームは他のすべてのチームに勝っているかを答えてください. 勝ち数による順位と $V$ の関係を説明してください.

<details class="protected" data-pass="yakagika">
    <summary> 回答例 </summary>

1. $V = \{(A, B), (A, C), (D, A), (B, C), (B, D), (C, D)\}$.

2. 満たしません. 反例は $(A, B) \in V$, $(B, D) \in V$ ですが $(A, D) \notin V$ です ($D$ が $A$ に勝っています).

3. 勝ち数は $A$ が 2, $B$ が 2, $C$ が 1, $D$ が 1 です. 1 位は $A$ と $B$ が同数で並び, $A$ は $D$ に負けているので, 1 位のチームが他のすべてのチームに勝っているわけではありません. 勝ち数による順位は, 勝ち数という数の大小 (狭義の全順序) を使って付けたものであり, 試合の勝敗の関係 $V$ そのものの性質ではありません. $V$ は推移律を満たさないので, $V$ だけからは順位は決まりません. 順位を付けるには, 勝ち数のような, 大小の決まった値へ対象を移す規則を別に決める必要があります.

</details>
