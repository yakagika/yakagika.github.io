# manufacturing_items.csv

データサイエンス実践 第10章 (Transformer の学習) の事例で使う, 製造業の品目名と中分類の表です.

出典: 総務省「日本標準産業分類 (令和5年7月告示) 分類項目名, 説明及び内容例示」の大分類 E 製造業
(https://www.soumu.go.jp/main_content/000935526.pdf). 同資料の内容例示を加工して作成しました.
このデータは総務省が作成したものではありません.

加工の内容:

- 細分類ごとの内容例示 (含まれる例と, 含まれない例のうち正しい細分類が示されているもの) を抜き出し,
  例の末尾の「製造業」を落として品目名にしました (「バター製造業」→「バター」).
- 管理, 補助的経済活動を行う事業所の細分類と, 製造業の外に分類される例は除きました.
- 同じ品目名が複数の中分類に出るものは除き, 同じ中分類の中で重なるものは 1 件にしました.

列:

| 列 | 内容 |
|---|---|
| `item` | 品目名 |
| `mid_code` | 中分類の番号 (09〜32) |
| `mid_name` | 中分類の名前 |
| `small_code` | 小分類の番号 (3 桁) |
| `fine_code` | 細分類の番号 (4 桁) |
